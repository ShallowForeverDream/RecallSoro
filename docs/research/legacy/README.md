# 本地个人资料管理器

直接使用：双击 `C:\College\竞赛\竞赛历程\整理\启动资料管理器.cmd`。

## 三个主要功能

- 默认“资料列表”Tab，一条资料一行，不预先加载图片。点击行查看大图/PDF第一页与附件清单；“编辑”打开台账表单。
- 可按日期、名称、分组、更新时间、编号排序；日期/名称/分组表头可切换升降序。支持混用点号、短横线等日期格式；日期不详的记录始终排在最后，不根据文件名或赛事名猜日期。
- “图片浏览”Tab保留图片卡片，只显示已有附件的记录，可按年月时间轴或主题分组浏览；两个Tab共享筛选和提交包选择。

1. 台账：新增、编辑、归档记录；奖项、成绩、排名分开；用途标签；保存前版本检查；编辑历史可恢复字段。
   主题分组独立于资料类型和核对状态，支持算法、网安、科研、思政，以及不适合四组的“未分组”。页面上方按组筛选，每条记录均可手动改组；在某组中新增时默认归入该组。
2. 图片检索：搜索名称、备注、附件名及本地OCR文字；分类、年份、状态和有无附件筛选；缩略图预览、原图/PDF打开；上传副本，完全相同内容不重复存储。
3. PDF提交包：每项默认加入一份证明，可在详情加入其他附件；调整顺序、改目录标题、旋转；生成A4等比排版PDF，可附材料目录；保留提交清单与原文件SHA-256。

## 数据与原件

- 新台账保存在 `C:\College\竞赛\竞赛历程\整理\资料管理数据\catalog.sqlite3`，不修改旧JSON、Word和证书原件。
- 首次导入读取最新竞赛历程；后续日常信息在管理器维护。不会自动监视Word变化，也不会回写Word。原历程是否记载可手动更新。
- 首次导入只对同一行、同一赛事采用Word新值；遇到插行或改名不盲目覆盖。旧核对备注保留在历史导入信息中。
- 每日首次操作留一份SQLite快照；每次改字段保存旧版本。每日快照是本地恢复点，不替代独立备份。
- 页面“导出台账备份”只备份数据和路径，不含图片本体。完整备份请复制整个“整理”目录，务必包含“资料管理数据”。
- 上传图片或PDF复制到资料管理数据/uploads；不读取浏览器未选中的本地文件。Word等材料请先自行另存PDF。
- OCR缓存、缩略图、台账和PDF均只在本机保存。原件可能有身份证号、学号、签名及二维码；导出**不自动脱敏**。

## 运行环境和限制

- 本机使用Codex配套Python（Pillow、pypdf、pypdfium2、reportlab）；没有额外安装依赖。不依赖外网和云服务。
- 监听127.0.0.1，默认8766；占用时尝试后续9个端口，不终止其他进程。重开同一资料库会复用已有服务。
- Windows本地OCR对上传图片识别一次，对扫描PDF默认只OCR第一页；可选中任何附件“重新识别”。文字PDF提取文本（全部页面），文件名和台账始终可检索。无法保证手写、低清和花体文字识别准确。
- PDF导出保留输入文件不变，统一A4等比放置，不裁切；图片副本按约300dpi上限缩放并以JPEG质量92压缩，原始高清图片不变。PDF内容合并不保留可交互表单、链接和数字签名效力。输出是提交副本，不是签名原件。
- 单附件30MB、PDF最多300页；每批最多100份、总材料页最多500页。尚不提供按指定MB目标自动压缩或自动脱敏。
- 已保存附件暂不提供删除入口；可归档记录，避免误删原件。
- 关闭浏览器不会停止服务；页面左侧“关闭本地服务”可停止。未设置开机启动、自动任务或后台磁盘监控。
